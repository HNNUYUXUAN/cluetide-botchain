【BOT Chain Mainnet 最终核验｜ClueTide】

项目名称：ClueTide
项目定位：面向 Web3 团队的 AI Agent 发布协作与交付核验工具。
英文主张：Approve an exact release. Verify what shipped.

项目简介：
ClueTide 让 Web3 团队把 AI Agent 的创作成果变成共同认可、受控发布、可独立核验的交付。以项目发布页为切入点，团队能够清楚确认每一版由谁批准、按什么意见修订，以及实际交付了什么。

ClueTide 将 Agent 准备、合作方审阅、签名更正、版本重审、一次性启动和实际交付核验串成完整流程。Agent 交接原件与测试证据；审阅方批准准确版本，或签署具体修改要求；Agent 按意见修订；执行方用自己的钱包启动受控发布；协作方保存验收包并独立核验。

BOT Chain 为参与方提供共同的承诺记录：任务角色、版本摘要、审阅决定、一次启动及交付回执。每次修改形成新版本并重新取得批准，每次执行消耗一次授权，实际 Gas 和操作记录公开可查。签名更正让 Agent 得到明确的修订要求，可携带验收包让每位协作者掌握交付证据。产品把修订责任、发布权限和交付核验落实为一条可操作的协作流程。

四、用户主网交易路径
1. 打开产品，导入 Agent 审阅包；也可从 Prepare a browser release 准备自己的演示任务。
2. 匿名检查目的、准确版本、逐行差异、HTML 预览和测试证据。
3. 连接提案/执行钱包，切到 BOT Mainnet，登记任务并提交准确版本。
4. 指定审阅钱包批准该版本，或 Request correction 后签署无需 Gas 的更正意见。
5. Agent 读取签名意见生成新版本，修改后重新提交和批准。
6. 执行钱包 Authorize one start，受控发布批准产物；原包与启动 Hash 可在另一浏览器恢复同一 attempt。
7. 登记回执，核对原件/签名、当前链上承诺与实际下载文件，并导出可离线核验的验收包。
测试钱包需准备少量 BOT 支付 Gas。现有验收任务可匿名核验；发起新任务时应配置自己的提案、审阅和执行角色。

七、AI Native 协作能力与已实现成果
Agent CLI 提供 export、feedback、wait、verify-package 等命令，与浏览器和服务使用同一交换规范。签名更正绑定准确版本、清单、交易和正文摘要，Agent 能读取可核验的修改要求，再交接下一版。
公开产品已部署 Vercel，Neon PostgreSQL 持久保存原件、意见和执行结果；服务按请求启动，三次数据库冷启动实测均小于 6 秒。
完整验收任务已跑通改版重审、签名反馈、一次启动、实际发布、链上回执和验收包核验。跨浏览器恢复实测进一步验证：协作者可以凭原始包与启动交易 Hash，在独立浏览器恢复同一执行 attempt、完成实际发布并导出验收成果。
