# Security policy

This repository is a release-authorization portfolio and local demonstration. Witness v2 has automated verification and static-analysis coverage; it has not received an independent production audit.

Report a potential vulnerability through [GitHub private vulnerability reporting](https://github.com/HNNUYUXUAN/cluetide-botchain/security/advisories/new) when available. If unavailable, open a minimal issue requesting a private contact without publishing exploit details or sensitive evidence.

Include affected revision, protocol version, reproducible local steps and expected impact. Use Anvil/public test identities. Do not include wallet secrets, personal evidence, live authorization tokens or production transactions. See the protocol threat model for trust roots, RPC assumptions, Safe boundaries and publisher recovery.

Historical v1 deployment artifacts are retained for verification. New real-network v2 deployments require the separate deployment checklist and an operational review. The demo server must remain loopback-only.
